# Sys Monitor Tool
Este proyecto incluye scripts para monitorear recursos, realizar backups y analizar logs.

## Instalación
1. Clonar el repositorio.
2. Dar permisos de ejecución a los scripts con `chmod +x`.
3. Configurar Cron para automatización.

## Uso
- `./resource_monitor.sh` para ver el estado del sistema.
- `./backup_manager.sh` para generar backups.
- `./log_analyzer.sh` para analizar logs.
